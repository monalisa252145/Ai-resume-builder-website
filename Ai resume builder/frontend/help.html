❓ Help & About

Everything you need to know about ResumeAI

🚀 Getting Started

  1. Register or Login to your account
  2. Go to Resume Builder and fill in your details
  3. Use AI buttons to generate professional content
  4. Choose a template from the right panel or Templates page
  5. Preview your resume live on the right panel
  6. Use ATS Analyzer to check keyword match
  7. Click Download PDF to get your resume

🤖 AI Features

  • 📝 Generate Summary – AI creates a professional summary based on your profile
  • 💼 Improve Experience – Converts simple job descriptions into bullet points
  • 🚀 Improve Project – Makes your project descriptions more impactful
  • ⚡ Suggest Skills – Recommends relevant skills for your job role
  • 📊 ATS Analysis – Analyzes keyword match between resume and job description
💡 AI features require a valid API key configured in the backend. Without it, you'll see an error message and can continue editing manually.

🛠️ Technical Stack

  • Frontend: HTML5, CSS3, Vanilla JavaScript
  • Backend: Java 17, Spring Boot 3.2, Spring Security, JWT
  • Database: MongoDB with Spring Data MongoDB
  • PDF: Flying Saucer + iText PDF library
  • AI: Groq API (llama3-8b-8192 model)
  • Authentication: BCrypt + JWT tokens

📌 Tips

  • Your resume auto-saves every 2 seconds while you type
  • If you close the browser, your draft is saved in localStorage
  • Use the ATS Simple template for maximum job board compatibility
  • Add quantifiable achievements (e.g., "Reduced load time by 40%")
  • Match your skills section to keywords in the job description
